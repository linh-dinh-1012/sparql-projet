# Démonstrateur : extraction et curation de données via SPARQL

Ce mini-projet propose un exemple concret de transformation de données issues d’un graphe RDF en un jeu de données exploitable pour la recherche.

À partir d’un endpoint SPARQL ouvert, des informations sur des auteurs français sont extraites puis traitées en Python afin d’être nettoyées, simplifiées et rendues réutilisables dans des analyses ultérieures ou dans une perspective d’intégration à une base de connaissances.

## Objectifs

- interroger un graphe de connaissances ;
- transformer les résultats en données tabulaires ;
- améliorer la qualité et la cohérence des informations ;
- produire un dataset prêt pour la réutilisation scientifique.

## Technologies

SPARQL, Python, pandas, requests.

## Utilisation

Ouvrir le notebook et exécuter les cellules dans l’ordre pour reproduire l’extraction et les étapes de curation.
